# EngCompAlert — código-fonte recebido

Este pacote contém o arquivo de código principal enviado nesta conversa.

## Importante
Este ZIP **não é o projeto Expo completo**. Para abrir e executar o aplicativo em outro computador,
também são necessários os demais arquivos do projeto, como `package.json`, `app.json` ou
`app.config.*`, `tsconfig.json`, arquivos de configuração e eventuais telas/componentes adicionais.

O arquivo recebido contém a implementação da tela do EngCompAlert e a configuração de conexão
com o Supabase. O amigo que receber este pacote poderá consultar o código, mas não terá aqui
tudo o que é necessário para instalar e executar o aplicativo sozinho.

## Próximo passo para gerar o ZIP completo
No computador onde o projeto funciona, compacte a pasta inteira do projeto EngCompAlert
(incluindo `package.json` e os arquivos de configuração), mas exclua a pasta `node_modules`
para reduzir o tamanho. Depois, esse ZIP completo poderá ser compartilhado.

## Segurança
O código contém a URL e uma chave publicável do Supabase. Chaves publicáveis são destinadas
ao uso no cliente, mas o banco deve estar protegido por políticas RLS adequadas. Nunca inclua
uma chave `service_role` ou outro segredo administrativo em um aplicativo distribuído.
